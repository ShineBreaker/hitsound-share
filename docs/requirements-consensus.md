> 本文档为需求对齐期（grilling 三轮）的决策记录快照，随源码共享；实施过程中的口径演进以代码与 AGENTS.md 为准。

> 状态：草案（待事实调研补齐 + oracle 审查 + 用户确认）

> 对齐方式：grilling skill 三轮前沿提问

## 一句话

一个让所有 osu! 玩家共享、试听、下载铺面音效（hitsound）的站点：上传 zip 音效包，站点解析出包内文件层级与元数据，以"分类树 + 文件表 + 波形"的形式浏览，每个音效可单独试听、单独下载，也可整包下载。

## 核心理念

**让所有人都能够参与共享** —— 参与门槛只保留一个：osu! 账号登录。其余一切（分类、元数据、波形）由站点自动完成。

## 已定决策

### 产品

| # | 决策 | 结论 |
|---|------|------|
| P1 | 共享粒度 | 包 + 文件两级：上传 zip（≤500MB，2026-09-29 从 100MB 放开；另支持单个音频文件直传），解析出包内文件；文件级展示与试听/下载，支持整包下载 |
| P2 | 分类体系 | 不预定义全局分类；左侧树 = 各包顶层节点 + zip 包内部文件夹层级（参考图模型） |
| P3 | 试听 | MVP 逐个文件点播 + 波形点击跳播；"模拟节奏连播"排入后续迭代 |
| P4 | 波形图 | 要做：上传时生成波形峰值数据，前端渲染，带播放进度指示 |
| P5 | 页面范围 | 单页 MVP：左树 + 右表 + 顶部登录/上传；只含参考图内元素 |
| P6 | 列表字段 | 图内全做：文件名、格式、时长、采样率、采样深度、声道、波形 |
| P7 | 上传表单 | 仅 zip 文件 + 包名（默认取 zip 文件名）；作者/时间/解析自动 |
| P8 | 内容治理 | 上传者可删自己的包；管理员可删任意包；无举报/审核/封禁 |
| P9 | 界面语言 | 中文为主，架构预留 i18n 双语接口 |

### 明确不做（MVP 非目标）

- 搜索、点赞、下载计数、评论
- 举报系统、先审后发
- 主题切换（固定 Argon 暗色）
- 节奏连播试听（后续迭代）

### 技术

| # | 决策 | 结论 |
|---|------|------|
| T1 | 存储/部署 | Cloudflare 免费全家桶起步（R2 + Workers/Pages + D1），$0 验证，需求大了再迁移 |
| T2 | 域名 | 免费子域验证期：站点 *.pages.dev，音频 R2 公开访问走 r2.dev（有限流，验证期可接受），后续绑自定义域 |
| T3 | 前端 | SvelteKit |
| T4 | 视觉 | osu!lazer Argon 设计语言（暗色、紫色强调、大圆角），仅重设计图内元素 |
| T5 | 上传鉴权 | osu! OAuth v2，登录后才能上传/删除 |
| T6 | 上传链路 | 浏览器 → R2 直传（预签名 URL）；波形/元数据解析在浏览器端完成（Web Audio API），随元数据提交 |

## 已核实事实（2026-09-29，官方文档来源，详见 research/storage-and-facts.md）

- **Cloudflare 免费额度**：R2 = 10GB 存储 + 100 万 Class A + 1000 万 Class B 操作/月，**出口流量免费**，超出 $0.015/GB-月；Workers/Functions = 10 万请求/天 + 10ms CPU/次；D1 = 5GB + 500 万行读/天；Pages 静态请求免费不限量，构建 500 次/月。
- **⚠️ R2 激活需绑卡**：开通 R2 必须绑定支付方式（社区有 2026-03 被预扣 $5 的报告）。"$0 起步"实际含义 = 需绑卡、免费额度内不产生费用。
- **⚠️ r2.dev 公开子域官方明文"限流、仅限开发"** → 架构决定：音频不走 r2.dev 公开桶，走 Pages Functions 从 R2 绑定代理读取（同在免费额度内，支持 Range 分段播放）。
- **osu! OAuth v2**：客户端在 osu.ppy.sh/home/account/edit#oauth 注册；授权码模式；登录只需 `identify` scope；`GET /api/v2/me`（Bearer）返回 id/username/avatar_url；回调 URL 必须与注册值完全一致；localhost 可用于调试。
- **Argon 视觉规格（lazer 源码提取）**：紫阶 #b299ff/#8c66ff/#7047eb/#5933cc/#3d2e6b（主强调 #8c66ff，经典 osu! 紫 #8866ee），品牌粉 #ff66aa；暗背景族 #1b171c/#28222a/#362e38；圆角 5px；字体 Torus（**付费字体，web 端用开源替代**，候选 Exo 2 / Inter）。
