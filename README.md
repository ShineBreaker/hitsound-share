# hitsound-studio

为 osu! 的 mapper 打造的铺面音效（hitsound）分享站点——找音效、听音效、拿音效、组音效、试音效，一站完成。

> **推荐自行托管**：考虑到音效素材的版权归属与站点运营成本，我们自建的实例不对公众开放。本项目从第一天起就按「fork 即可私有部署」设计——全栈跑在 Cloudflare 免费计划内，十来分钟就能拥有一个属于你自己的音效站。部署步骤见下方[「自行托管」](#自行托管推荐)与 [docs/deployment.md](docs/deployment.md)。

## 功能全景

### 浏览与试听

- **免登录，开箱即用**：浏览、试听、下载不注册、不限速，打开网页就能挑音效
- **原汁原味的目录结构**：音效包内的文件夹层级原样呈现（taiko、claps-snares、whistles……），熟悉的整理方式直接搬进浏览器
- **边听边挑，所见即所听**：每个音效自带波形图，点哪播哪；格式、时长、采样率、采样深度、声道一目了然——挑音效就像在本地音频管理器里一样顺手
- **新手友好**：首次访问自动进入分步引导，`?` 键随时打开帮助

### 下载

- **想要哪个下哪个**：单个音效直接下载，原始文件名一个不改
- **整包 zip 一键带走**：由浏览器按包的**当前内容**实时拼包，下载内容始终与站内现状一致

### 上传与共享（osu! 账号登录）

- **一个压缩包就能上架**：拖入 zip / rar / 7z 即可，解包、哈希、校验全部在浏览器本地完成
- **社区共享，越传越省**：内容寻址去重让每个音效在云端只存一份，别人传过的音效自动秒传，不用再传第二遍
- **附加上传**：把新音效追加进自己已有的包，不必另开新包
- **在线管理**：大类/小类行内改名，整包 / 小类 / 多选文件删除，即时生效

### 组装面板（Kit）

- 右下角悬浮面板，把挑中的音效放入 `normal / soft / drum × hitnormal / hitwhistle / hitfinish / hitclap` 格子，自动按 osu! 皮肤命名（如 `drum-hitnormal2.wav`）打包成可直接使用的 hitsound 组
- 文件表勾选多个音效一次性入格，格子内自动连续编号（对应 osu! 音效组下标）
- 按 QWERTY / ASDFGH / ZXCVBN 键位即时试听 normal / soft / drum 三行音效，像打键盘认音一样组套

### 谱面集工作流（.osz）

- **导入本地 .osz 谱面包**：全程只存在于浏览器内存，不上传、不入库、不留痕
- **覆盖计划**：按文件名匹配谱面集根目录音效，将被替换的条目高亮标示，替换了什么一目了然
- **一键导出**合并后的 .osz，放进 osu! 直接开打
- **osu!cad 实时预览**：悬浮窗内嵌 osu!cad 自动游玩谱面，格子里的音效改动实时生效、热刷新不打断播放——边调边听，改完即所得

### 站点管理（可选）

- **站点访问密码门**：给整个站加一道访问密码，未解锁时所有数据接口一律拒绝访问，适合团队与私域共享
- **管理员体系**：超管在线维护管理员名单，管理员可管理站内全部内容与站点密码
- **上传配额**：单文件 ≤10MB / 每日 5 包 / 全局存储水位三重闸门，管理员豁免前两项

## 特色

- **服务器极轻，浏览器干重活**：解包（rar / 7z 走按需加载的 wasm）、去重哈希、整包 zip 组装全在浏览器端完成，服务端只做清单、核验与代理回退，没有重型计算——这是它能整个跑在 Cloudflare 免费计划上的根本原因
- **内容寻址存储**：音频按 sha256 寻址，全站每个音效只存一份；引用计数账本自动回收不再被引用的空间，库越大、共享越省
- **隐私友好**：谱面集导入不出浏览器，上传解包在本地完成，服务器永远只接触它需要接触的字节
- **优雅降级**：不配置上传相关环境变量，站点就自动变成一个纯只读音效库——登录与上传入口隐藏，浏览/试听/下载照常工作
- **osu! editor 风格 UI**：手写 CSS 橄榄绿主题、中文界面、波形可视化播放，专为长时间挑音效的场景打磨；无 UI 组件库、无外链 CDN、严格 CSP

## 谁适合用

- **mapper**：试音、下音、组装专属 hitsound 组、套进谱面实时预览效果，一条龙
- **音效作者**：一个压缩包上架作品，社区内秒传播、免重复上传
- **团队 / 社区**：自托管一个私域音效库，用密码门控制访问范围，素材与成员都自己掌握
- **玩家**：从站内挑一套顺手的 hitsound，下载即用

## 自行托管（推荐）

我们强烈建议你部署一份自己的实例，而不是依赖任何公共站点：

1. **版权可控**：音效素材的授权因包而异，私有部署把分发范围掌握在自己手里
2. **成本可控**：全栈跑在 Cloudflare 免费计划（Pages Functions + R2 + D1 免费额度），中小社区规模零成本
3. **数据自主**：音频在 R2、元数据在 D1，全部资源都在你自己的 Cloudflare 账号下，随时可迁走
4. **部署不难**：Git 连上 Pages 推送即自动构建，配好环境变量、执行一次 schema.sql 即可上线

快速步骤（完整细节与验证清单见 [docs/deployment.md](docs/deployment.md)）：

1. Fork 或导入本仓库到你的 GitHub，创建 D1 数据库与 R2 桶
2. 创建 Cloudflare Pages 项目并连接仓库，配置 R2 CORS
3. 在 osu! 网站创建 OAuth 应用（回调地址 `https://<你的域名>/api/auth/callback`），把 6 个上传链路变量与可选的管理员/站点密码变量配进 Pages
4. 远程执行一次 `schema.sql` 初始化数据库
5. 推送 `main`，自动构建部署完成

只想要一个纯浏览的只读音效站？连上传变量都不用配齐——上传入口会自动隐藏，其余功能照常。
