# hitsound-share

为 osu! 玩家与 mapper 打造的铺面音效（hitsound）分享站——找音效、听音效、拿音效，一站完成。

**立即体验：<https://hitsound-share.pages.dev>**

## 为什么好用

- **免登录，开箱即用**：浏览、试听、下载全部功能不注册、不登录、不限速，打开网页就能挑音效
- **边听边挑，所见即所听**：每个音效自带波形图，点哪播哪；格式、时长、采样率、采样深度、声道一目了然——挑音效就像在本地音频管理器里一样顺手
- **原汁原味的目录结构**：音效包内的文件夹层级原样呈现（taiko、claps-snares、whistles……），熟悉的整理方式直接搬进浏览器
- **想要哪个下哪个**：单个音效直接下载，整包 zip 一键带走，原始文件名一个不改
- **分享你的音效包，只需一个 zip**：用 osu! 账号一键登录，拖入 zip 即可上架；浏览器本地完成解析与校验，相同文件自动秒传，别人传过的音效不用再传第二遍
- **社区共享，越传越省**：内容寻址去重让每个音效在云端只存一份，大家的音效包共同组成一个不断长大的公共音效库

## 界面

osu!lazer Argon 风格设计，中文界面，波形可视化播放，专为长时间挑音效的场景打磨。

## 参与共享

1. 打开 <https://hitsound-share.pages.dev>
2. 右上角用 osu! 账号登录
3. 拖入你的 hitsound zip，坐等秒传上架

已收录的音效包欢迎自由试听与下载，无需任何账号。
