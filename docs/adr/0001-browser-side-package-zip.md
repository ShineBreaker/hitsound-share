# 整包下载在浏览器端实时拼 zip

Cloudflare 免费计划单请求上限 50 个子请求，服务端从 R2 读取 2400+ 个 blob 拼包必然越界；上传时额外保存 original.zip 又会让下载内容与附加、改名后的包状态脱节，还要多付一份存储。因此 v4 起停止上传和保存 original.zip：服务端只返回下载清单（预签名 GET 直连 R2，缺少 R2 密钥时回退 `/api/blob` 同源代理），由浏览器并发拉取并以 STORE 模式流式打包。组装面板使用同一套打包实现。

## Consequences

- 超大包在不支持 File System Access 的浏览器里需要在内存中攒完整个 zip，这是已接受的代价。
- R2 的 CORS 必须放行站点域名，否则直连拉取失败。
